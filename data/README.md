# Data scripts

This folder keeps the data pipeline that is still in use:

- `crawl_longchau_full.py`
- `process_raw_to_api.py`

## Crawl Long Châu

`crawl_longchau_full.py` crawls raw product data into PostgreSQL.

## Process raw data to API

`process_raw_to_api.py` maps raw crawl data into API-ready catalog data.
